Videos and links from this tab

Every file type is sent to Awesome Downloader. The browser download is canceled only after the desktop app accepts it; otherwise it continues in the browser.

Desktop downloads

Start the Windows app and register the browser bridge first. HLS VOD supports TS/fMP4 output; DASH, encrypted-key HLS and most sites are handled through the page-video button. DRM-protected streams (Netflix, Disney+, etc.) cannot be downloaded.
